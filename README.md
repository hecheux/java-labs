# Labs on Java

Здесь находятся 5 отдельных работ по разным темам. 
В процессе выполнения я работал с сокетами, клиент серверным взаимодействием, сервлетами, сессиями, CSS и JavaScript.
---
### Что есть в репозитории

Лабораторная работа 1  
Чат для двух пользователей по UDP

Лабораторная работа 2  
Многопользовательский чат по TCP

Лабораторная работа 3  
Сервлет для записной книжки

Лабораторная работа 4  
Доска объявлений с авторизацией через HttpSession и оформлением через CSS

Лабораторная работа 5  
Двухуровневый список с динамическим раскрытием элементов через JavaScript

Для каждой лабораторной работы есть своя папка с исходным кодом и отдельный README с коротким описанием.
