# UDP Chat

# Чат для двух пользователей

# О чем работа
В этой лабораторной работе реализован простой текстовый чат для двух пользователей. 
Программа работает по модели клиент сервер. 
Один пользователь запускается на стороне сервера, второй на стороне клиента. 
Обмен сообщениями идет по протоколу UDP.

# Что сделал
Я написал серверную и клиентскую части приложения. 
Добавил ввод адреса и порта через командную строку. 
Реализовал команды для задания имени пользователя, отправки сообщений и выхода из программы. 
Также сделал автоматический вывод входящих сообщений на экран.

# Как работает
Сначала запускается сервер и начинает слушать указанный порт. 
Затем запускается клиент и подключается по нужному адресу и порту. 
После запуска пользователь может ввести имя через команду @name, 
отправлять обычные текстовые сообщения и завершать работу через команду @quit. 
Все принятые сообщения сразу появляются на экране.
